# gati2026

Websites and games built live with students at **Pinellas Academy of Math and Science** for the Great American Teach-In 2026. Live at **https://gati.alexhackney.com**.

In each classroom the kids shouted out ideas, and Claude Code built a one-file site from them on the projector in a couple of minutes. Tweaks ("add a dragon") went in on the spot. Everything in this repo is what came out of those sessions.

## How they were built

### Claude Code skills
The classroom workflow is three [Claude Code](https://claude.com/claude-code) skills:

- **`/gati <class> <grade> <idea>`** builds the site. It parses the class, grade and idea, writes a small fragment (extra `<head>` tags, CSS, HTML body, JS), merges it into a shared template and serves it locally. Follow-up requests edit the existing file in place.
- **`/gati-deploy <class>`** copies the site into this repo, rebuilds the landing page, commits `added <class>` and pushes to `main`.
- **`/gati-reset <class>`** blanks a class back to the template.

The skills live in `~/.claude/skills/` and drive a local workspace (`~/code/other/gati`, not part of this repo) with the template, `compose.py`, and deploy/publish scripts.

### What a site is
Each class is **one self-contained `index.html`**: no build step, no framework, no bundler. The template provides:

- a title bar, footer and animated gradient background
- big `.btn` buttons that play a sound and throw confetti when clicked
- a small "bling kit" of JS helpers: `beep`, `tune`, `confetti`, `floaty`, `wiggle`, `say`
- readable-from-the-back-of-the-room sizing for a 1080p projector

Art is emoji or inline SVG only, so there are no image downloads.

### Libraries (vendored in `public/_lib/`)
Every library is copied locally rather than loaded from a CDN, because classroom wifi can fail. Only Google Fonts is loaded externally.

- [Tailwind CSS](https://tailwindcss.com): utility classes
- [animate.css](https://animate.style): ready-made animations
- [GSAP](https://gsap.com): tweening
- [three.js](https://threejs.org) (r160): 3D scenes, used by the drifting and T-Rex games
- [Howler.js](https://howlerjs.com): audio
- [Alpine.js](https://alpinejs.dev): light interactivity

Confetti comes from the template's built-in `confetti()` helper, not a library.

### Kid-safety rules
Baked into the `/gati` skill: no forms or text inputs, no external links, iframes or scripts, no real people, nothing scary or violent, and no copyrighted characters or brands.

## Repo layout

```
public/               everything Forge serves
  index.html          landing page (generated; don't edit by hand)
  _lib/               vendored JS/CSS libraries
  <class-name>/       one folder per class: index.html + meta.json ({"grade": N})
scripts/
  build-index.py      regenerates public/index.html from the class folders
  add-analytics.py    adds the Fathom Analytics tag to deployed pages
```

The landing page is generated by `scripts/build-index.py`. It lists every folder in `public/` that has an `index.html`, using the page `<title>` as the name and `meta.json` for the grade, sorted lowest grade first.

## Adding a class by hand
Everything served lives in `public/`.

1. Create `public/<class-name>/index.html` (its `<title>` becomes its name) and, optionally, `meta.json` with `{"grade": 3}`.
2. Run `python3 scripts/build-index.py` to refresh the landing page.
3. `git add -A && git commit -m "added <class-name>" && git push`

Forge deploys on push, and the class appears at `https://gati.alexhackney.com/<class-name>/`.

## Hosting (Laravel Forge)
1. Forge → server → **New Site**: domain `gati.alexhackney.com`, project type **Static HTML**, web directory `/public`.
2. Site → **Git Repository**: provider GitHub, repo `alexhackney/gati2026`, branch `main`, uncheck "Install Composer dependencies".
3. Site → **Deployments**: enable **Quick Deploy**. Deploy script:
   ```
   cd $FORGE_SITE_PATH
   git pull origin $FORGE_SITE_BRANCH
   ```
4. DNS: add an `A` record `gati` on `alexhackney.com` pointing to the server IP.
5. Site → **SSL**: Let's Encrypt for `gati.alexhackney.com`.
